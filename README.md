📝 Descripción del Proyecto

Este repositorio contiene una aplicación web sencilla creada para la práctica de comandos de gestión de ramas, etiquetas (tags), resoluciones de fusiones (merges) y colaboraciones mediante Forks y Pull Requests en GIT y GitHub.

📁 Estructura del Sitio Web

El sitio consta de las siguientes páginas e historias de desarrollo:

Página de Inicio (index.html): Contiene la cabecera principal del proyecto, el menú de navegación y la información sobre el centro.

Página de Horario (horario.html): Presenta una tabla estructurada con el horario lectivo.

Página Sobre Mí (sobremi.html): Incluye detalles personales y académicos.

🔀 Historial de Ramas y Versiones (Tags)

El flujo de trabajo sigue la gestión de ramas con Git Flow simplificado:

main: Rama principal estable.

desarrollo: Rama integrada para el desarrollo de nuevas características.

feature1: Rama auxiliar para la creación de la sección "Sobre Mí".

Etiquetas / Versiones:

V1.0: Estado inicial con la estructura básica del proyecto y navegación inicial.

V2.0: Fusión de la rama feature1 en la rama desarrollo con incorporación de la imagen y secciones adicionales.

V3.0: Fusión completa de desarrollo en la rama principal main con todo el sitio integrado.

🚀 Instrucciones para Clonar e Instalar Localmente

Clona el repositorio en tu equipo:

git clone https://github.com/tu-usuario/Act2GIT_TuNombre.git


Accede al directorio del proyecto:

cd Act2GIT_TuNombre


Abre el archivo index.html en tu navegador de preferencia.

⚙️ Archivos Ignorados (.gitignore)

El proyecto incluye un archivo .gitignore configurado para evitar la subida de documentación pesada o no relevante, como los archivos en formato .pdf.
